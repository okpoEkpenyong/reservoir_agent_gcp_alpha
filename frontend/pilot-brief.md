Exzing-EnergyX — Pilot Brief
============================

Purpose
-------
Validate data ingestion, emission calculation and verification readiness for a Maritime CO₂ monitoring MVP.

Scope
-----
- Duration: 4–6 weeks
- Vessels: 3–10 vessels (single operator or mixed)
- Data types: voyage logs (CSV or API), bunker receipts, AIS-derived distances (optional)
- Deliverables: ingestion & calculation report, sample verified voyages (spot check), UX feedback report

What we need from partner
-------------------------
- Access to sample voyage logs or CSV exports (device_id, fuel_type, fuel_amount, timestamp, voyage_id)
- Bunker receipts for spot verification where available
- Point of contact for data mapping and on-ship crew questions

Pilot goals & success criteria
------------------------------
- >95% successful ingestion of provided CSV/API payloads after onboarding
- <5% parsing errors after first week
- Verified CO₂ figures for at least 2 voyages using partner-provided evidence
- Actionable UX improvements identified and implemented

Security & ownership
--------------------
- All partner data remains owned by partner
- Data in transit encrypted (HTTPS). Temporary access keys for pilot use
- Pilot-specific non-disclosure / DPA available on request

Next steps
----------
1. Kickoff call (30 minutes) to confirm data mapping & timeline
2. Technical onboarding (1–2 hours)
3. Pilot run (4–6 weeks)
4. Pilot closeout & verification report
